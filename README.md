# Roblox Coin Counter

This project contains a script for a coin counter in Roblox Studio. The script creates a TextLabel at the top of the screen to display the number of coins the player has collected. The coin counter is a useful tool for games that involve collecting coins or other items, as it provides a clear and easy-to-read display of the player's progress.

## Install

1. Download the `CoinCounterScript.lua` file from the project repository.
2. Open Roblox Studio.
3. Create a new script in the StarterPlayerScripts folder.
4. Copy the contents of `CoinCounterScript.lua` into the new script.

## Use

1. Run the game in Roblox Studio.
2. The coin counter will appear at the top of the screen, displaying the number of coins the player has collected.
3. To update the coin count, you can use the `updateCoinCount` function in the script. For example, you can call `updateCoinCount(10)` to set the coin count to 10.
